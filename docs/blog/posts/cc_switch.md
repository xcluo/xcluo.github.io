CC-Switch 是一个 Claude Code 的本地路由工具，支持多 API 供应商切换。

<!-- more -->

1. 下载 [CC-Switch](https://github.com/farion1231/cc-switch/releases)
2. 右上角添加新供应商
3. 高级选项中选择"OpenAI Chat Completion"
4. 填入 API_KEY，BASE_URL(无需/chat/completions) 以及 MODEL_NAME，保存
5. 左上角设置
6. 通用部分勾选"跳过 Claude Code 初次安装插件"
7. 路由部分勾选"在本主页面显示本地路由"，"路由总开关"以及"Claude 路由启用"

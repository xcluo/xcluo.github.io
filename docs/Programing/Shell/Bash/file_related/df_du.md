# df 和 du 命令

## df - 磁盘空间使用情况

### 语法

```bash
df [OPTIONS] [文件]
```

Option

| 选项 | 说明 |
|------|------|
| `-h` | 以人类可读的方式显示（KB、MB、GB） |
| `-H` | 同 `-h`，但以 1000 为基准而非 1024 |
| `-T` | 显示文件系统类型 |
| `-i` | 显示 inode 信息而非块使用情况 |
| `-a` | 显示所有文件系统，包括虚拟文件系统 |
| `-t <类型>` | 只显示指定类型的文件系统 |
| `-x <类型>` | 排除指定类型的文件系统 |

### 常用命令

```bash
# 基本显示
df

# 人类可读格式
df -h

# 显示文件系统类型
df -hT

# 显示 inode 使用情况
df -i

# 显示所有文件系统
df -a

# 只显示 ext4 类型
df -t ext4

# 查看指定文件/目录所在文件系统
df -h /home
```

## du - 目录/文件磁盘占用

### 语法

```bash
du [OPTIONS] [文件或目录]
```

Option

| 选项 | 说明 |
|------|------|
| `-h` | 以人类可读的方式显示 |
| `-s` | 只显示总计 |
| `-d <N>` | 显示深度 N 的汇总（GNU du） |
| `-a` | 显示所有文件的统计，不仅仅是目录 |
| `--max-depth=N` | 最大显示深度 |
| `-c` | 最后显示总计 |
| `-k` | 以 KB 为单位 |
| `-m` | 以 MB 为单位 |
| `-x` | 跳过不同文件系统 |
| `--time` | 显示最后修改时间 |

### 常用命令

```bash
# 基本显示（当前目录）
du

# 人类可读格式
du -h

# 只显示总计
du -sh

# 查看指定目录大小
du -sh /var/log

# 深度为 1 的汇总
du -h --max-depth=1

# 显示所有文件
du -ah

# 最后显示总计
du -ch /path/to/dir

# 按大小排序（需要 sort）
du -h /path | sort -h

# 显示目录树及大小（深度 2）
du -h --max-depth=2

# 只显示大于 100MB 的目录
du -h --max-depth=1 /path | awk '$1 ~ /G/ || tonumber($1) > 100 {print}'
```

### 常见用法

```bash
# 查找当前目录下最大的 10 个文件/目录
du -ah . | sort -rh | head -n 10

# 统计某用户家目录大小
sudo du -sh /home/*

# 排除某目录计算大小
du -sh --exclude='*.log' /var
```
